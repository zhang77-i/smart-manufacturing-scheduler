# 数学模型

对订单 i、兼容机器 m，令 x[i,m] 表示厂内分配，o[i] 表示外发，s[i]、e[i] 表示开始和结束时间。对可选的前后置弧 (i,j)，i 是 j 的前置订单。核心约束为：

1. 每个订单恰好分配到一台兼容机器或外发；
2. 若分配到机器 m，则 e[i] = s[i] + p[i,m]；
3. s[i] 不早于订单释放时间和机器最早可用时间；
4. 厂内完成时间不晚于到达后 24 小时硬截止；
5. 每台机器上的可选区间满足 NoOverlap。
6. 当前置与后续订单都在厂内加工时，满足 s[j] >= e[i]；任一订单外发时该内部前后置弧不激活。

目标逐阶段求解：

1. 最小化外发数并固定该阶段 incumbent；
2. 在固定外发数下最大化按批次交期完成数，再固定该 incumbent；
3. 在前两层固定后最小化总逾期与等待。

若某阶段只得到 FEASIBLE，后续阶段优化的是当前已知 incumbent 下的次级目标，不能宣称整个词典序问题已经全局最优。

JSON 实例通过订单的可选 `predecessors` 字段声明前置关系。加载时会检查未知订单、重复前置、自环和有向环；构造启发式按拓扑可行顺序调度，独立校验器再次检查最终开始与结束时间。

887 单全规模聚合实验对应原案例中的独立订单排程，没有把这个通用可选字段计入历史结果。
