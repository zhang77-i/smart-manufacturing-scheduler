# Scheduling Benchmark

## Purpose

Compare different scheduling strategies under the same production instances.

## Methods

| Method | Description |
|---|---|
| EDD | Earliest Due Date heuristic |
| Greedy | Priority based construction |
| CP-SAT | Constraint programming optimization |

## Metrics

- Makespan
- Total tardiness
- Runtime

## Evaluation Process

1. Generate production instances
2. Run each algorithm
3. Collect scheduling metrics
4. Compare solution quality
