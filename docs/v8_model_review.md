# v8 模型审计与修正

原 v8 已正确完成两项关键修复：启发式解只作为 hint 而不固定变量；厂内订单显式满足 24 小时硬截止。但它仍使用 BIG × on-time − tardiness − waiting 的单一加权目标，因此所谓 gap 是复合目标 gap，不能直接解释为按期订单数距离最优值的百分比。

当前版本改为三个独立求解阶段，并分别保存状态与 gap：

- 阶段一最少外发；
- 阶段二固定外发数后最多按期；
- 阶段三固定前两层后最少逾期与等待。

同时移除硬编码解释器路径、禁止把 FEASIBLE 写成全局最优，并让独立校验器从最终排程记录重新验证兼容性、时长、释放时间、机器可用时间、硬截止与重叠。
